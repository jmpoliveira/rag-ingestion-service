# Release notes: September 2026

## Dark mode for the agent workspace

Agents can now switch the agent workspace to dark mode from their profile menu. The setting is
personal and follows the operating system by default. The help centre and the chat widget keep
the colours chosen by the administrator.

## Bulk merge

Agents can select several tickets from the same requester in a view and merge them in one
step. The oldest ticket is kept, as with single merges (see the Ticket lifecycle article).

## Tag autocomplete

When adding tags to a ticket, Tessera now suggests existing tags as you type, which reduces
near-duplicate tags such as "refund" and "refunds".

## SLA timer in ticket lists

Views can now show a column with the time left before each ticket breaches its SLA policy.
Tickets that have already breached are shown in red.

## Billing page

The billing page now shows the amount and date of the next invoice, and lists the seats added
or removed during the current period.

## Fixes

- Chat transcripts with very long messages were cut off when converted into tickets.
- Scheduled exports failed for workspaces whose time zone had a half-hour offset.
